**Destiné aux clients BYZCLUB**  
**Version** : 1.0 - Février 2026

## 🎯 Bienvenue dans votre Espace d'Approbation

Votre équipe créative vous propose régulièrement des **concepts de contenus** (Reels Instagram, Posts, etc.).  
Cet espace vous permet de **consulter, valider ou ajuster** ces propositions en toute simplicité.

---

## 🚀 Accéder à vos Concepts

1. Connectez-vous à votre **Espace Client** : `/client-portal`
2. Dans le menu latéral, cliquez sur **💡 Approbation de Concepts**
3. Vous arrivez sur votre tableau de bord de validation

---

## 📊 Vue d'Ensemble

### Cartes Résumé

Au sommet de la page, 3 cartes vous donnent une vue instantanée :

| Carte | Description |
|-------|-------------|
| **⏳ En attente** | Concepts proposés qui attendent votre validation |
| **✅ Approuvés** | Concepts que vous avez validés |
| **❌ Rejetés** | Concepts que vous avez refusés avec vos raisons |

---

## 🔍 Onglets de Filtrage

Naviguez facilement entre les différents statuts :

## 💡 Consulter un Concept

Chaque carte de concept affiche :

- **Type** : 🎬 Reel ou 📸 Post
- **Titre** : Nom du concept
- **Description** : Résumé court (2 lignes)
- **Objectif** : But marketing du contenu
- **Statut** : Badge coloré (En attente / Approuvé / Rejeté)

**➡️ Cliquez sur "Voir détails"** pour ouvrir la vue complète.

---

## ✅ Approuver un Concept

### Étapes :

1. **Ouvrez le concept** en cliquant sur "Voir détails"
2. Lisez attentivement :
   - La **description complète**
   - L'**objectif** marketing
3. (Optionnel) Ajoutez un **commentaire** dans le champ prévu
4. Cliquez sur le bouton vert **"Approuver ce concept"**
5. ✨ **Confirmation** : Le concept passe en "Approuvé"

### Que se passe-t-il ensuite ?

- Le concept devient **final** (ne peut plus être modifié)
- L'équipe reçoit votre validation
- La production peut démarrer
- Le concept apparaît dans votre onglet **"Approuvés"**

---

## ❌ Rejeter un Concept

### Pourquoi rejeter ?

- Le concept ne correspond pas à votre image de marque
- Le ton ou le style ne convient pas
- Vous souhaitez des modifications importantes

### Étapes :

1. **Ouvrez le concept** en cliquant sur "Voir détails"
2. Descendez jusqu'à la section **"Votre décision"**
3. Cliquez sur **"Rejeter ce concept"** (section dépliable)
4. **⚠️ OBLIGATOIRE** : Expliquez la raison du rejet
   - Soyez précis et constructif
   - Exemple : "Le ton est trop formel, notre audience préfère un style décontracté"
5. (Optionnel) Ajoutez des commentaires supplémentaires
6. Cliquez sur **"Confirmer le rejet"**

### Que se passe-t-il ensuite ?

- Le concept passe en **"Rejeté"**
- L'équipe **lit votre feedback**
- Le concept peut être **modifié** selon vos retours
- Vous recevez une **version mise à jour** à valider à nouveau

## 🎨 Types de Concepts

### 🎬 Reel (Vidéo courte)
- **Format** : Vidéo verticale (9:16)
- **Durée** : 15 à 90 secondes
- **Plateformes** : Instagram Reels, TikTok
- **Objectif** : Viralité, engagement rapide
- **Design** : Badge rose-rouge

### 📸 Post (Publication statique)
- **Format** : Image ou carousel
- **Durée** : Contenu permanent
- **Plateformes** : Instagram Feed, Facebook, LinkedIn
- **Objectif** : Information, témoignage, annonce
- **Design** : Badge bleu-indigo

## 💬 Bonnes Pratiques de Feedback

### ✅ Feedback Constructif

**Bon exemple** :
> "Le concept est intéressant mais le ton est trop sérieux pour notre audience jeune. Pourriez-vous rendre le message plus dynamique et ajouter une touche d'humour ?"

**Mauvais exemple** :
> "Je n'aime pas."

### ✅ Soyez Spécifique

Mentionnez précisément ce qui doit changer :
- Ton de communication
- Éléments visuels
- Structure du message
- Appel à l'action
- Public cible

### ✅ Délai de Réponse

- **Recommandé** : 24-48h
- Cela permet de respecter le calendrier éditorial
- Vous pouvez prendre votre temps si nécessaire

## 🔄 Workflow de Révision

Si vous rejetez un concept, voici ce qui se passe :

```
1. Vous rejetez avec raison
    ↓
2. L'équipe lit votre feedback
    ↓
3. Le concept est modifié
    ↓
4. Vous recevez une "Version mise à jour"
    ↓
5. Vous validez la nouvelle version
```

**💡 Astuce** : Le label "Version mise à jour" apparaît sur les concepts renvoyés après modification.

## ❓ Questions Fréquentes

### **Puis-je modifier un concept approuvé ?**
Non, une fois approuvé, le concept est final. Si vous changez d'avis, contactez votre équipe qui créera un nouveau concept.

### **Combien de temps ai-je pour répondre ?**
Aucune limite technique, mais nous recommandons 24-48h pour maintenir le calendrier de publication.

### **Puis-je discuter d'un concept avec l'équipe ?**
Oui ! Utilisez le champ "Commentaires" ou contactez directement votre chargé de compte via l'onglet "Contact".

### **Que se passe-t-il si je ne réponds pas ?**
Le concept reste en "En attente". L'équipe peut vous relancer par email.

### **Puis-je annuler une décision ?**
Les décisions sont finales, mais vous pouvez toujours demander à l'équipe de créer une variante ou un nouveau concept.

### **Les concepts sont-ils liés à mes mandats ?**
Oui, certains concepts peuvent être rattachés à un mandat spécifique pour plus de contexte.
